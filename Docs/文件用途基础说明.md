# Notify-Relay-android 项目结构与文件用途说明

> 本文基于当前仓库实际代码校验整理（`:app` 版本 `2.169.0` / `versionCode 10329325`）。
> 若后续重构目录或模块，请同步更新本文档。

---

## 一、项目概览

### 1.1 项目信息

| 项 | 值 |
|---|---|
| 项目名（rootProject） | `NotifyRelay` |
| 仓库根目录 | `Android/`（工作区 `e:\GitHub-code\Notify-Relay\Android`） |
| 应用 ID / `:app` namespace | `com.xzyht.notifyrelay` |
| compileSdk / targetSdk | 37 / 37 |
| `:app` minSdk | 31（Android 12） |
| `:core` minSdk | 31 |
| `:base` / `:data` / `:superislandui` / `:checkupdata` / `:lsp` minSdk | 29（取 `libs.versions.minSdk`） |
| `:nativecore` minSdk | 29 |
| `:scrcpy` minSdk | 26（子模块自带配置） |
| 模块数量 | 9 个 |
| 主源码 `.kt` 文件数 | 约 307 个（不含测试） |

### 1.2 模块清单

| 模块 | namespace | 说明 | 是否 Git 子模块 |
|---|---|---|---|
| `:app` | `com.xzyht.notifyrelay` | 主应用（UI、业务 feature、同步） | 否 |
| `:base` | `notifyrelay.base` | 基础工具库（无内部模块依赖） | 否 |
| `:core` | `notifyrelay.core` | 核心工具库（依赖 `:base`） | 否 |
| `:data` | `notifyrelay.data` | 数据层（Room / 配置 / 持久化，依赖 `:base`） | 否 |
| `:superislandui` | `github.xzynine.superislandui` | 超级岛（SuperIsland）悬浮 UI 渲染 | 否 |
| `:checkupdata` | `github.xzynine.checkupdata` | 更新检查 | 是 |
| `:scrcpy` | `io.github.miuzarte.scrcpyforandroid` | Scrcpy 投屏 | 是 |
| `:nativecore` | `com.xzyht.notifyrelay.nativecore` | Rust 核心 FFI 绑定（JNA），依赖 `:base` | 否（内含 `notify-relay-core` 子模块） |
| `:lsp` | `com.xzyht.notifyrelay.lsp` | LSPosed 模块（超级岛鉴权绕过） | 否 |

> 子模块来源（`.gitmodules`）：
> - `checkupdata` → `git@github.com:xzy-nine-common/checkupdata-android.git`（branch `main`）
> - `scrcpy` → `git@github.com:xzy-nine/ScrcpyForAndroid.git`（branch `library`）
> - `nativecore/notify-relay-core` → `https://github.com/NotifyRelay/core.git`（branch `main`）
>
> 根 `build.gradle.kts` 对 `checkupdata`/`scrcpy` **不应用** ktlint，子模块代码在其各自仓库维护。

### 1.3 模块依赖关系

```
:app ──┬── :data ─────────── :base
       ├── :core ─────────── :base
       ├── :superislandui ─┬ :core ── :base
       │                   ├── :data ── :base
       │                   └── :base
       ├── :scrcpy ────────┬ :base
       │                   └── :data ── :base
       ├── :nativecore ───── :base
       ├── :checkupdata        （无内部依赖）
       ├── :lsp                （无内部依赖）
       └── :base
```

`buildSrc/` 为 Gradle 构建辅助工程，`lsp/`、`nativecore/` 之外还有 Rust 侧代码（位于 `nativecore/notify-relay-core`）。

## 四、构建相关

- 版本号来自根目录 `version.properties`（由 `update.yml` 在 push 到 `main` 时按 conventional commits 语义回写）；CI 可用 `-PversionName/-PversionCode` 或环境变量 `VERSION_NAME/VERSION_CODE` 覆盖。
- `:app` 在 release 构建时启用 ABI splits（`arm64-v8a`、`x86_64` + universal），debug 仅生成 universal APK。
- `preBuild` 依赖 `generatePermissionNotes`：解析 `AndroidManifest.xml` 中 `<uses-permission>` 上方注释，生成 `res/raw/permission_notes.txt`，供协议页（`GuideAgreementPage`）展示权限用途。**权限用途只需维护 Manifest 注释，不要在 Kotlin 中手抄**。
- `:app` 声明 `aidl = true`、`buildConfig = true`、Compose 开启；`packaging.merges += "META-INF/xposed/*"` 用于合并 `:lsp` 的 LSPosed 入口声明。
- ktlint 应用于除 `checkupdata`、`scrcpy` 之外的所有模块。
